# 项目开发规范

本目录包含项目开发过程中的各种规范和最佳实践。

## 目录结构

- [01-naming-conventions.md](./01-naming-conventions.md) - 文件命名规范
- [02-code-style.md](./02-code-style.md) - 代码风格规范（待添加）
- [03-git-workflow.md](./03-git-workflow.md) - Git 工作流规范（待添加）
- [04-testing-standards.md](./04-testing-standards.md) - 测试规范（待添加）

## 使用说明

1. 所有规范文档都使用 Markdown 格式编写
2. 文件名使用 kebab-case 命名方式
3. 文档编号使用两位数，便于排序和扩展
4. 每个规范文档都应该包含：
   - 规范说明
   - 具体示例
   - 注意事项

## 规范更新

- 规范的更新需要经过团队讨论和评审
- 更新后的规范需要及时同步给团队成员
- 建议定期回顾和优化规范内容
