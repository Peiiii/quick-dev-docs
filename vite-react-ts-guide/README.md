# Vite-React-TS Project Setup Guide

本目录包含了一系列文档，指导你如何使用Vite、React、TypeScript、pnpm、Tailwind CSS和Shadcn UI搭建现代化前端项目。

## 文档结构

- [Project Overview](./index.md) - 项目技术栈简介和快速开始指南
- [01-Project Initialization](./01-project-initialization.md) - 创建Vite项目并安装基础依赖
- [02-Configure Tailwind CSS](./02-configure-tailwind-css.md) - 添加和配置Tailwind CSS
- [03-Install Shadcn UI](./03-install-shadcn-ui.md) - 设置和配置Shadcn UI组件库
- [04-Examples and Troubleshooting](./04-examples-and-troubleshooting.md) - 组件使用示例和常见问题解决方案

## 环境要求

- Node.js (推荐v16+)
- pnpm (`npm install -g pnpm`)

## 快速开始

如果你想快速开始，可以直接查看[Project Overview](./index.md)文档，其中包含了完整的命令列表。

如果你需要更详细的配置步骤和解释，请按顺序阅读各个文档。
